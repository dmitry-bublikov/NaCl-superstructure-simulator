# Модуль 0 — Родительские ячейки

`Модуль 0` строит каталоги максимальных родительских трансляционных ячеек, которые используются последующими модулями генерации стехиометрий и структур.

В модуль входят две программы:

| Программа | Геометрическая оболочка по умолчанию | Максимальный индекс | Выходной файл |
|---|---:|---:|---|
| `Parent_cells_CF32.cpp` | `2 x 2 x 2` родительских кубических ячейки | `N = 32` | `CF32_parents.txt` |
| `Parent_cells_CF108.cpp` | `3 x 3 x 3` родительских кубических ячейки | `N = 108` | `CF108_parents.txt` |

Здесь `N` — число катионных позиций в трансляционной ячейке. Для полностью занятой структуры NaCl-типа соответствующая анионная подрешётка также содержит `N` позиций.

---

## Назначение

Модуль ищет формы трансляционных ячеек ГЦК-подрешётки катионов, которые могут быть представлены в пределах выбранной геометрической оболочки CF. Эквивалентные ячейки объединяются с учётом кубической симметрии родительской решётки, после чего избыточные ячейки удаляются проверкой вложения трансляционных решёток.

Итогом является компактный каталог **максимальных родительских ячеек**. Именно этот каталог используется на следующих этапах программы.

На этапе глобальной стехиометрии нет необходимости повторять расчёт для каждой формы ячейки. Ячейки с одинаковым `N` имеют одно и то же пространство глобальных стехиометрий, поэтому стехиометрии достаточно сгенерировать один раз для каждого различного `N`, а затем использовать для всех родительских ячеек с тем же индексом.

## Правило отбора

Кандидатная трансляционная ячейка включается в исходный каталог, если:

1. существует хотя бы один её базисный параллелепипед, помещающийся в выбранную осесимметричную кубическую геометрическую оболочку;
2. её индекс удовлетворяет `N <= Nmax`;
3. ячейки, связанные одной из 48 знако-перестановочных симметрий кубической родительской решётки, считаются эквивалентными.

Затем полученные неэквивалентные ячейки сравниваются по вложению трансляционных решёток. Ячейка удаляется, если другая ячейка из того же каталога является её собственной трансляционной суперячейкой и способна содержать любое её периодическое упорядочение хотя бы при одной относительной кубической ориентации.

Ячейки, не покрываемые никакой другой ячейкой каталога, образуют итоговое множество максимальных родительских ячеек.

## Нормальная форма Эрмита (HNF)

Программы представляют трансляционные решётки в примитивном базисе ГЦК и приводят каждую целочисленную матрицу базиса к **нормальной форме Эрмита (Hermite normal form, HNF)**.

HNF — это каноническая форма базиса целочисленной решётки. Разные матрицы базиса могут описывать одну и ту же трансляционную решётку; приведение к HNF даёт однозначное представление и позволяет удалять такие дубликаты.

Для полноранговой матрицы HNF `3 x 3`:

```text
N = |det(H)|
```

где `N` — индекс решётки и одновременно число катионных позиций соответствующей трансляционной ячейки.

HNF сама по себе не является алгоритмом геометрического поиска ячеек. Сначала программа перебирает допустимые тройки базисных векторов ГЦК, а затем использует HNF для канонического представления найденной трансляционной решётки.

## Формат выходного файла

Каждая программа создаёт один итоговый каталог. Отдельный `summary`-файл не создаётся: сводная информация и распределение по `N` находятся в заголовке самого каталога.

Типичная запись:

```text
# MAXIMAL_PARENT 01 / 25
# original_catalogue_cell = 7
CELL 7
  index_cation_sites: 4
  representative_row_HNF: [1 0 0; 0 1 0; 0 0 4]
  cubic_orbit_key_HNF: [1 0 0; 0 1 0; 0 0 4]
  primitive_fcc_basis_rows: [...]
  cartesian_basis_a0: [...]
  bbox_span_a0: ...
  metric_a0: a=... b=... c=... alpha=... beta=... gamma=...
```

### Значение полей

| Поле | Значение |
|---|---|
| `MAXIMAL_PARENT` | порядковый номер в итоговом каталоге максимальных родительских ячеек |
| `original_catalogue_cell` | номер ячейки до удаления покрываемых классов |
| `index_cation_sites` | индекс `N`, равный числу катионных позиций |
| `representative_row_HNF` | представитель трансляционной решётки в строковой HNF |
| `cubic_orbit_key_HNF` | канонический ключ орбиты относительно 48 кубических симметрий |
| `primitive_fcc_basis_rows` | выбранный компактный базис в целочисленных координатах примитивной ГЦК-решётки |
| `cartesian_basis_a0` | тот же базис в обычных декартовых координатах в единицах `a0` |
| `bbox_span_a0` | осевой размер показанного базисного параллелепипеда |
| `metric_a0` | длины базисных векторов и углы между ними |

## Параметры командной строки

Обе программы поддерживают:

```text
--box B
--nmax N
--output FILE
```

Запуск CF32 по умолчанию:

```bat
Parent_cells_CF32.exe
```

Запуск CF108 по умолчанию:

```bat
Parent_cells_CF108.exe
```

Пример с явным указанием параметров:

```bat
Parent_cells_CF32.exe --box 2 --nmax 32 --output CF32_parents.txt
```
