## Stoichiometry_* — Генератор стехиометрий для CIF32/108

## Соглашение по именованию модулей

Каждый исполняемый файл соответствует определенной конфигурации компонентов.

**Формат:** `XY` (две цифры)

- Первая цифра (`X`) = количество катионных компонентов
- Вторая цифра (`Y`) = количество анионных компонентов

### Примеры:
- `84` — 8 катионных компонентов, 4 анионных компонента
- `73` — 7 катионных компонентов, 3 анионных компонента
- `52` — 5 катионных компонентов, 2 анионных компонента
- `11` — 1 катионный компонент, 1 анионный компонент

---

# Режимы расчета

Программа поддерживает два режима расчета в зависимости от числа позиций в суперячейке:

| Режим | Число позиций |
|-------|---------------|
| CF32  | 32            |
| CF108 | 108           |

При запуске пользователь выбирает желаемый режим:
Enter your choice:
1 - CF32
2 - CF108

text

---

# Доступные заряды

## Катионы
- Полный набор: `0 1 2 3 4 5 6 7`
  - `0` = вакансия
  - `1-7` = зарядовые состояния катионов

## Анионы
- Полный набор: `0 1 2 3`
  - `0` = вакансия
  - `1-3` = зарядовые состояния анионов (абсолютные значения; реальные заряды: `-1`, `-2`, `-3`)

---

# Выбор компонентов

Для систем с меньшим, чем максимальное, числом компонентов пользователь вручную выбирает желаемые зарядовые состояния.

**Формат ввода:** список зарядов через пробел, завершающийся `-1`

### Пример: 7-компонентная катионная система (модуль 74)

Возможный ввод:
0 1 2 3 4 5 6 -1

text
или
1 2 3 4 5 6 7 -1

text

### Пример: 6-компонентная катионная система (модуль 64)

Возможный ввод:
0 1 2 3 4 5 -1

text
или
1 2 3 4 5 6 -1

text

### Пример: 3-компонентная анионная система (модуль 83)

Возможный ввод:
0 1 2 -1

text
или
1 2 3 -1

text

# Значение comp-N

Обозначение `comp-N` означает, что выбирается `N` зарядовых состояний из полного набора зарядов.

### Пример для катионов:
`comp-5` может быть выбрано как:
0 1 2 3 4

text
или
1 2 3 4 5

text
или любой другой допустимый набор из пяти различных зарядов от `0` до `7`.

### Пример для анионов:
`comp-3` может быть выбрано как:
0 1 2

text
или
1 2 3

text
или любой другой допустимый набор из трех различных зарядов от `0` до `3`.

# Формат вывода

Программа генерирует все допустимые стехиометрические конфигурации, удовлетворяющие условию электронейтральности.

**Выходной файл:** `stoichiometry_XX.txt` (где `XX` соответствует номеру модуля)

### Пример вывода (модуль 73, CF32):

A5+1 B5+2 C5+3 D4+4 E4+5 F4+6 V5 0| X27-3 Y4-2 Z1-1 ch=90 1

A5+1 B5+2 C5+3 D4+4 E4+5 F4+6 V5 0| X28-3 Y2-2 Z2-1 ch=90 2

A5+1 B5+2 C5+3 D4+4 E4+5 F4+6 V5 0| X28-3 Y3-2 V1 0 ch=90 3

A5+1 B5+2 C4+3 D5+4 E4+5 F4+6 V5 0| X28-3 Y3-2 Z1-1 ch=91 4

text

### Пояснение формата вывода:

| Элемент | Описание |
|---------|----------|
| `A5+1`  | 5 атомов катиона с зарядом +1 |
| `B5+2`  | 5 атомов катиона с зарядом +2 |
| `V5+0`  | 5 вакансий (заряд 0) |
| `\|`    | Разделитель между катионами и анионами |
| `X27-3` | 27 атомов аниона с зарядом -1 |
| `Y4-2`  | 4 атома аниона с зарядом -2 |
| `Z1-1`  | 1 атом аниона с зарядом -3 |
| `ch=90` | Общий абсолютный заряд (проверка баланса) |
| `1`     | Порядковый номер стехиометрии |

# Схема работы программы

1. Запуск программы
2. Выбор режима расчета (CF32 или CF108)
3. Выбор конфигурации компонентов (номер модуля)
   - Выбор зарядов катионов (вручную или все)
   - Выбор зарядов анионов (вручную или все)
4. Выбор режима вывода (сохранять в файл или только на экран)
5. Генерация всех перестановок зарядов катионов и анионов
6. Генерация распределений стехиометрических коэффициентов
7. Проверка электронейтральности
8. Вывод валидных стехиометрий в файл (если выбран)
9. Отображение статистики (время выполнения, всего найдено)

# Возможности

Поддержка до 8 катионных компонентов

Поддержка до 4 анионных компонентов

Поддержка вакансий (заряд 0)

Поддержка размеров суперячеек CF32 и CF108

Устранение дублирующихся конфигураций через каноническое упорядочивание

Возможность выбора зарядов для конфигураций с уменьшенным числом компонентов

Полный перебор электронейтральных стехиометрий

Ограничения
Максимальное количество катионных компонентов: 8

Максимальное количество анионных компонентов: 4

Поддерживаемые числа позиций: только 32 (CF32) или 108 (CF108)

Заряды анионов хранятся как абсолютные значения; реальные заряды отрицательны

Выходной файл может стать очень большим (несколько ГБ для режима CF108)

Обработка ошибок
Ошибка	Решение
ERROR: Invalid choice!	Перезапустите и введите 1 или 2
ERROR: Cannot create file!	Проверьте место на диске и права
Invalid charge: X, ignored	Вводите заряды от 0 до max_charge
Total found: 0	Проверьте конфигурацию компонентов
