# Поиск локального баланса валентностей в CF32 и CF108

**English version:** [README.md](README.md)

Набор программ предназначен для отбора стехиометрий NaCl-подобных структур, для которых **существует хотя бы одно размещение ионов по узлам**, удовлетворяющее выбранному условию локального баланса валентностей. Для CF32 также предусмотрен отдельный генератор размещений для ограниченного класса задач.

## 1. Программы и их назначение

| Исходный файл | Структура | Проверяемый локальный баланс | Особенности |
| --- | --- | --- | --- |
| `Find-local-balance-32-32-a.cpp` | CF32: 32 катионных + 32 анионных позиции | **Вокруг анионов** | Смешанные анионы `X/Y/Z/V`, точный поиск, `D = 0` и `D > 0` |
| `Find-local-balance-32-32-c.cpp` | CF32: 32 катионных + 32 анионных позиции | **Вокруг катионов** | Смешанные катионы, катионные вакансии, точный поиск, `D = 0` и `D > 0` |
| `Find-local-balance-108-108-a.cpp` | CF108: 108 катионных + 108 анионных позиций | **Вокруг анионов** | Только **один заданный заряд аниона** и точный баланс `D = 0` |
| `Gen-structures.cpp` | CF32: 32 катионные позиции | **Перебор размещений для одной стехиометрии** | Используется **только с `Find-local-balance-32-32-a.cpp` для кодов компонентности `11, 21, 31, 41, 51, 61, 71, 81`** (от 1 до 8 катионных компонентов и ровно 1 анионный); один фиксированный целевой баланс |

**Важно:** программы `-a` и `-c` проверяют **разные** условия. Если одна стехиометрия присутствует в результатах обеих программ, это само по себе **не доказывает**, что оба условия выполняются *одновременно в одном и том же размещении*: каждая программа ищет своё допустимое размещение.

Все три фильтра записывают **исходные строки подходящих стехиометрий**, а не координаты атомов или полный список структур. Для генерации конкретных размещений служит отдельная программа `Gen-structures.cpp` в пределах указанной выше области применения.

## 2. Математический критерий

В NaCl-подобной структуре рассматривается шесть ближайших соседей противоположной подрешётки. В обозначениях ниже `D` (`delta`) — допустимое абсолютное отклонение от локального баланса; при `D = 0` требуется точное равенство.

**Баланс вокруг аниона** (`Find-local-balance-32-32-a.cpp`, `Find-local-balance-108-108-a.cpp`):

\[
\left|\sum_{j \in N(a)} q_j + 6z_a\right|\leq D,
\]

где `q_j` — положительные заряды соседних катионов, `z_a` — отрицательный заряд центрального аниона. Эквивалентный целевой заряд окружения: `6 × |z_a|`. Например, для `X⁻`, `Y²⁻`, `Z³⁻` целевые суммы равны `6`, `12` и `18`. В CF32, если **анионный центр вакантен**, локальное уравнение для него пропускается.

**Баланс вокруг катиона** (`Find-local-balance-32-32-c.cpp`):

\[
\left|\sum_{j \in N(c)} |z_j| - 6q_c\right|\leq D,
\]

где `|z_j|` — модули зарядов шести соседних анионов, `q_c` — заряд центрального катиона. Если **катионный центр вакантен**, локальное уравнение для него пропускается. Это зеркальная по графу соседства, но **не идентичная по критерию** задача.

## 3. Подготовка входных данных

### CF32: `Find-local-balance-32-32-a.cpp` и `Find-local-balance-32-32-c.cpp`

Обе программы ожидают файл:

```text
stoichiometry_N_32_32.txt
```

`N` — код компонентности набора стехиометрий, который вводится при запуске (например, `11`, `31`, `84`). **Первая цифра** указывает число катионных компонентов, **вторая** — число анионных: `31` означает 3 катионных и 1 анионный компонент, а `84` — 8 катионных и 4 анионных. Программа использует этот код для формирования имени файла.

Пример строки:

```text
A32+2 | Y32-2 ch=64 1
```

Здесь `A32+2` — 32 катиона с зарядом `+2`, `Y32-2` — 32 аниона с зарядом `-2`, `ch=64` и последний номер — дополнительные поля исходного набора. Допустимы катионные обозначения `A`–`G`, вакансия `V` (заряды `0…+7`), анионные `X`, `Y`, `Z` и `V` (заряды `0, -1, -2, -3`). Суммарные количества должны составлять **ровно 32 катионные и 32 анионные позиции**. Вакансии записываются, например, как `V4 0`.

### CF108: `Find-local-balance-108-108-a.cpp`

Эта программа ожидает **другое имя файла**:

```text
stoichiometry_N.txt
```

Катионная часть строки должна задавать **108 позиций**; доступны компоненты `A`–`G` и `V` с зарядом `0…+7`. Разные катионные компоненты должны иметь **разные заряды**. Например:

```text
A108+2 | Y108-2 ch=216 1
```

При чтении программа использует **только катионную часть до символа `|`**. Единый модуль заряда аниона (`0`, `1`, `2` или `3`) вводится **отдельно при запуске**. Поэтому пользователь должен сам убедиться, что выбранный заряд соответствует подготовленному набору: смешанные анионные заряды эта версия **не анализирует**.

## 4. Сборка в Windows (Visual Studio / MSVC)

Откройте **Developer PowerShell for Visual Studio 2022** или **x64 Native Tools Command Prompt** и перейдите в каталог проекта. Каждая команда создаёт отдельный `.exe`:

```powershell
cl Find-local-balance-32-32-c.cpp /O2 /Oi /Ot /EHsc /std:c++17 /Fe:find-local-balance-32-32-c.exe
cl Find-local-balance-32-32-a.cpp /O2 /Oi /Ot /EHsc /std:c++17 /Fe:find-local-balance-32-32-a.exe
cl Find-local-balance-108-108-a.cpp /O2 /Oi /Ot /EHsc /std:c++17 /Fe:find-local-balance-108-108-a.exe
cl Gen-structures.cpp /O2 /Oi /Ot /EHsc /std:c++17 /Fe:Gen-structures.exe
```

Входной файл должен находиться в **текущем рабочем каталоге**, из которого запускается соответствующий `.exe`.

## 5. Запуск фильтров CF32

### 5.1. Баланс вокруг анионов — `find-local-balance-32-32-a.exe`

```powershell
.\find-local-balance-32-32-a.exe
```

Программа запросит:

```text
Enter stoichiometry file number (e.g. 84): 11
Enter allowed deviation delta (e.g. 0): 0
```

В этом примере вход — `stoichiometry_11_32_32.txt`, а выход — **`local_balance_11_0.txt`**. Заряд каждого анионного компонента читается из самой строки стехиометрии; отдельного вопроса о заряде аниона **нет**.

При `D = 0` для подходящих случаев используются необходимые модульные ограничения (`mod 2`, `mod 3`) и сокращение по симметрии; для `D > 0` предусмотрены специализированные пути, а общие смешанные случаи проверяются точным поиском с ограничениями на количества анионных компонентов.

### 5.2. Баланс вокруг катионов — `find-local-balance-32-32-c.exe`

```powershell
.\find-local-balance-32-32-c.exe
```

Пример ответов на запросы тот же:

```text
Enter stoichiometry file number (e.g. 84): 11
Enter allowed deviation delta (e.g. 0): 0
```

Вход — `stoichiometry_11_32_32.txt`, выход — **`local_balance_11_0.txt`**. В этой версии размещаются анионные заряды, а вокруг катионных центров проверяются соответствующие суммы. Для `D = 0` используются точные модульные ограничения для транспонированной матрицы соседства CF32; также предусмотрены отдельные быстрые ветви для некоторых случаев `D > 0`.

**Внимание: конфликт выходных имён!** `-a` и `-c` используют **одинаковый шаблон `local_balance_N_D.txt`** и открывают выход на запись с перезаписью. Для одинаковых `N` и `D` **не запускайте их в одном каталоге без сохранения первого результата**. Можно использовать разные рабочие каталоги или переименовать первый файл *до* запуска второй программы, например:

```powershell
# Сразу после работы -a, до запуска -c
Rename-Item local_balance_11_0.txt local_balance_11_0_anion_centered.txt
# После завершения -c
Rename-Item local_balance_11_0.txt local_balance_11_0_cation_centered.txt
```

Обе CF32-программы работают в несколько потоков. Порядок строк в выходном файле может отличаться от исходного порядка; сравнивать результаты разных запусков нужно **без учёта порядка**.

## 6. Запуск CF108 — `find-local-balance-108-108-a.exe`

```powershell
.\find-local-balance-108-108-a.exe
```

Пример диалога:

```text
Enter stoichiometry file number (e.g., 31, 71): 11
Enter absolute UNIFORM anion charge for local balance (0, 1, 2, 3): 2
```

Будет прочитан `stoichiometry_11.txt` и создан **`local_balance_cf108_11_12_0.txt`**, где `12 = 6 × 2`. Отдельного ввода `D` нет: **всегда `D = 0`**.

Используется точное сокращение задачи CF108: 108 катионных позиций объединяются в **27 четвёрок** с одинаковыми зарядами внутри каждой четвёрки, а пространство решений задаётся **12 независимыми переменными** (ранг матрицы октаэдров равен 96). Поэтому необходимое условие — число катионов **каждого заряда кратно 4**. Также проверяется глобальный баланс зарядов. Эти условия необходимы, но **сами по себе не гарантируют существование размещения**: оставшиеся варианты проверяет точный solver.

CF108 читает вход **построчно** и использует ограниченный кэш; программа предназначена в том числе для больших файлов стехиометрий. Этот фильтр **не предназначен для локального баланса вокруг катионов или смешанных анионных зарядов**.

## 7. `Gen-structures.cpp`: генерация конкретных размещений CF32

**Область применения строго ограничена:** `Gen-structures.cpp` используется **только после `Find-local-balance-32-32-a.cpp` для кодов компонентности `11, 21, 31, 41, 51, 61, 71, 81`**. Это **не диапазон порядковых номеров стехиометрий**: первая цифра означает число катионных компонентов (**1–8**), вторая цифра — число анионных компонентов (**строго 1**). Генератор не является следующим этапом `Find-local-balance-32-32-c.cpp` или `Find-local-balance-108-108-a.cpp`.

Генератор использует **один фиксированный целевой локальный баланс `B`** вокруг аниона, поэтому его нельзя напрямую применять к смешанным анионным зарядам, для которых разные анионные центры требуют разных целевых сумм. Генератор перебирает размещения **одной** выбранной стехиометрии на 32 катионных позициях; в отличие от фильтра, он выводит **каждое найденное допустимое размещение**.

### Подготовка входного файла

1. Запустите `find-local-balance-32-32-a.exe` на соответствующем `stoichiometry_N_32_32.txt` с **`N ∈ {11, 21, 31, 41, 51, 61, 71, 81}`** (один анионный компонент).
2. Выберите **одну** подходящую строку с единым анионным зарядом из `local_balance_N_D.txt`.
3. Сохраните эту строку в отдельном текстовом файле **`for_generator_N_B_D.txt`**, где `B = 6 × |z_A|` и `D` — отклонение, использованное при фильтрации. Передача строки **не автоматическая**.

Например, для однокомпонентной по аниону стехиометрии `A32+2 | Y32-2 ch=64 1` и точного баланса:

```text
for_generator_11_12_0.txt
```

Содержимое этого файла (одна строка):

```text
A32+2 | Y32-2 ch=64 1
```

### Запуск и результаты

```powershell
.\Gen-structures.exe
```

На запрос введите **суффикс имени файла без `for_generator_` и `.txt`**:

```text
Enter stoichiometry file number (e.g., 31_12_0, etc.): 11_12_0
```

Программа прочитает `for_generator_11_12_0.txt` и создаст **`structuries_11_12_0.txt`**. Написание `structuries` сохранено **точно как в исходном коде**, это не `structures` и не `local_balance`.

Каждая выходная строка содержит **32 целочисленных заряда катионов**, соответствующих позициям `p1 … p32` в порядке, принятом в коде генератора. Это **распределения зарядов**, а не координаты атомов. Полный перебор может занимать много времени и создавать большие файлы.

## 8. Сводка имён файлов

| Программа | Вход | Параметры при запуске | Выход |
| --- | --- | --- | --- |
| CF32 `-a` | `stoichiometry_N_32_32.txt` | `N`, `D` | `local_balance_N_D.txt` |
| CF32 `-c` | `stoichiometry_N_32_32.txt` | `N`, `D` | `local_balance_N_D.txt` |
| CF108 `-a` | `stoichiometry_N.txt` | `N`, `|z_A|` | `local_balance_cf108_N_B_0.txt`, `B = 6 × |z_A|` |
| `Gen-structures` (CF32 `N = 11, 21, 31, 41, 51, 61, 71, 81`; только после `-a`) | `for_generator_N_B_D.txt` | `N_B_D` | `structuries_N_B_D.txt` |

## 9. Замечания

- Наличие строки в результате фильтра означает существование **хотя бы одного** допустимого размещения в принятой модели локального баланса; это **не доказательство термодинамической устойчивости** вещества.
- `D = 0` — точный локальный баланс; `D > 0` — разрешённое отклонение, используемое соответствующими CF32-программами. Для CF108 доступно только `D = 0`.
- Для сравнения результатов двух CF32-фильтров сохраняйте оба файла отдельно и учитывайте, что порядок вывода в многопоточном режиме может меняться.
- Имена входных файлов и выходов выше соответствуют **реально реализованным шаблонам в представленных исходниках**; особенно важно не путать `stoichiometry_N.txt` для CF108 с `stoichiometry_N_32_32.txt` для CF32.
