Программа 1: find-local-balance.exe
Назначение
Поиск стехиометрических составов, удовлетворяющих условию локального баланса валентностей.

Входные данные
Файлы стехиометрий: stoichiometry_N.txt (где N - номер файла)

Параметры ввода:

Номер файла стехиометрии

Заряд аниона (0, 1, 2, 3)

Допустимое отклонение от локального баланса

Выходные данные
Файл: local_balance_N_B_D.txt

N - номер файла стехиометрии

B - локальный баланс (заряд аниона × 6)

D - допустимое отклонение

Алгоритм работы
Чтение входного файла со стехиометриями

Для каждой стехиометрии:

Определение зарядов и количеств катионов

Перебор всех возможных комбинаций катионов по 32 позициям

Проверка локального баланса для каждого октаэдра

Проверка соблюдения стехиометрических ограничений

Запись найденных стехиометрий в выходной файл

Запуск в cmd или powershell
find-local-balance.exe
Программа запросит:

text
Enter stoichiometry file number (e.g., 71, 41, etc.): 31
Enter charge of anion for local balance (e.g., 0, 1, 2, 3): 2
Enter the deviation from the local balance: 0
Пример использования

# Входной файл: stoichiometry_31.txt
# Выходной файл: local_balance_31_12_0.txt

Программа 2: gen-structures.cpp
Назначение
Генерация всех возможных сверхструктурных вариантов для заданной стехиометрии.

Входные данные
Файл стехиометрии: for_generator_X_Y_Z.txt

X - номер стехиометрии

Y - локальный баланс

Z - допустимое отклонение

Параметры ввода:

Имя файла в формате X_Y_Z

Выходные данные
Файл: local_balance_X_Y_Z.txt

Содержит все найденные комбинации катионов по 32 позициям

Алгоритм работы
Чтение входного файла с одной стехиометрией

Определение зарядов и количеств катионов

Полный перебор всех комбинаций катионов по 32 позициям

Проверка локального баланса для 16 октаэдров

Проверка стехиометрических ограничений

Запись всех найденных вариантов в выходной файл

Запуск
Запуск в cmd или powershell
gen-structures.exe
Программа запросит:

text
Enter stoichiometry file number (e.g., 31_12_0, etc.): 31_12_0
Пример использования
bash
# Входной файл: for_generator_31_12_0.txt
# Выходной файл: local_balance_31_12_0.txt
📁 Структура входных файлов
Формат файла стехиометрии
text
A8+3 B4+2 C2+1 | ...
Где:

A8+3 - катион A с количеством 8 и зарядом +3

B4+2 - катион B с количеством 4 и зарядом +2

C2+1 - катион C с количеством 2 и зарядом +1

Формат файла для gen-structures
text
A8+3 B4+2 C2+1 | ...
Тот же формат, но используется для одной конкретной стехиометрии.

📊 Структура выходных данных
Для find-local-balance
text
[исходная строка стехиометрии]
Содержит только строки, удовлетворяющие локальному балансу.

Для gen-structures
text
z1 z2 z3 z4 z5 z6 z7 z8 z9 z10 z11 z12 z13 z14 z15 z16 z17 z18 z19 z20 z21 z22 z23 z24 z25 z26 z27 z28 z29 z30 z31 z32
Где z1...z32 - заряды катионов в 32 позициях (индексы 1-8 соответствуют катионам A-H и вакансии V).

🔄 Полный цикл работы


Шаг 1: Генерация стехиометрий под разные компонентности

Шаг 2: find-local-balance - поиск составов с соблюдением локального баланса

Шаг 3: gen-structures - построение сверхструктурных вариантов

📝 Примечания
Обе программы используют одинаковый алгоритм проверки локального баланса

find-local-balance обрабатывает несколько стехиометрий, gen-structures - одну

Обе программы выводят время выполнения и количество найденных вариантов

Для корректной работы необходим файл с соответствующим номером

🛠️ Компиляция
Windows (MSVC)
bash
cl find-local-balance.cpp /O2 /Oi /Ot /EHsc /Fe:find-local-balance.exe
cl gen-structures.cpp /O2 /Oi /Ot /EHsc /Fe:gen-structures.exe
