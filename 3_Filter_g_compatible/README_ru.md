# Cf_g_compat.cpp — Filter for geometrically compatible structures

## Назначение
Программа предназначена для удаления дублирующихся кристаллических структур, которые являются **геометрически совместимыми** (эквивалентными с точностью до поворотов осей симметрии).

## Принцип работы
Программа проверяет эквивалентность структур с учётом:
- Поворотов вокруг 1-й оси (4 варианта)
- Поворотов вокруг 2-й оси (4 варианта)
- Поворотов вокруг 3-й оси (4 варианта)
- Инвертированных вариантов (перевёрнутые оси)

## Алгоритм
1. Чтение входного файла со структурами
2. Первая структура автоматически сохраняется как уникальная
3. Для каждой новой структуры:
   - Проверка эквивалентности с учётом поворотов 1-й оси
   - Проверка эквивалентности с учётом поворотов 2-й оси
   - Проверка эквивалентности с учётом поворотов 3-й оси
4. Если структура не эквивалентна ни одной из сохранённых — добавляется
5. Запись всех уникальных структур в выходной файл

## Входные данные
- Файл: `structuries_X.txt` (где `X` — например `31_12_0`)
- Содержит наборы из 32 целых чисел (заряды катионов в позициях)

## Выходные данные
- Файл: `structuries_X_f1.txt`
- Содержит только уникальные структуры (без дубликатов)

## Запуск
Cf_g_compat.exe

Программа запросит:
Enter stoichiometry file number (e.g., 31_12_0, etc.): 31_12_0

Пример
# Входной файл: structuries_31_12_0.txt
# Выходной файл: structuries_31_12_0_f1.txt

Ограничения
Максимальное количество уникальных структур: 5000 (определено в #define A 5000)

Поддерживается до 32 катионных позиций

Компиляция
cl Cf_g_compat.cpp /O2 /Oi /Ot /EHsc /Fe:Cf_g_compat.exe

Компиляция - Windows (MSVC)

```cl Cf_g_compat.cpp /O2 /Oi /Ot /EHsc /Fe:cf_g_compat.exe```
