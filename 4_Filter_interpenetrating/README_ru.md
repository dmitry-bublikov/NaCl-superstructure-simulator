# Cf_interpen.cpp — Filter for interpenetrating structures

## Назначение
Программа предназначена для удаления дублирующихся кристаллических структур, которые являются **взаимопроникающими** (эквивалентными с точностью до перестановок позиций в октаэдрах).

## Принцип работы
Программа проверяет эквивалентность структур с учётом:
- Поворотов октаэдров (6 вариантов для каждого октаэдра)
- Инверсий (перевёрнутых вариантов)
- Перестановок катионных позиций внутри октаэдров

## Алгоритм
1. Чтение входного файла со структурами
2. Первая структура автоматически сохраняется как уникальная
3. Для каждой новой структуры:
   - Проверка эквивалентности октаэдру 1 (CF32-1)
   - Проверка эквивалентности остальным 31 октаэдрам (CF32-2 ... CF32-32)
4. Если структура не эквивалентна ни одной из сохранённых — добавляется
5. Запись всех уникальных структур в выходной файл

## Входные данные
- Файл: `structuries_X_f1.txt` (где `X` — например `31_12_0`)
- Содержит наборы из 32 целых чисел (заряды катионов в позициях)

## Выходные данные
- Файл: `structuries_X_f2.txt`
- Содержит только уникальные структуры (без дубликатов)

## Запуск
Cf_interpen.exe
Программа запросит:

Enter stoichiometry file number (e.g., 31_12_0, etc.): 31_12_0

Пример
## Входной файл: structuries_31_12_0_f1.txt
## Выходной файл: structuries_31_12_0_f2.txt
Ограничения
Максимальное количество уникальных структур: 5000 (определено в #define A 5000)

Поддерживается до 32 катионных позиций

Компиляция - Windows (MSVC)

```cl Cf_interpen.cpp /O2 /Oi /Ot /EHsc /Fe:cf_interpen.exe```
