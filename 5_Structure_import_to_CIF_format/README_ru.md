# Import_to_cif — Конвертация структуры в формат CIF

## Назначение
Программа предназначена для генерации CIF-файла (Crystallographic Information File) на основе пользовательских данных о катионах, анионах и их позициях в кристаллической решётке.

---

## Принцип работы
Программа считывает из текстовых файлов:
1. Свойства катионов (символ, заряд, атомный вес, радиус)
2. Свойства анионов (символ, заряд, атомный вес, радиус)
3. Последовательность из 32 катионов (их коды)
4. Координаты и CIF-параметры для 32 катионных позиций
5. Координаты для 32 анионных позиций

На основе этих данных генерируется CIF-файл с полной кристаллической структурой.

---

## Входные данные

### 1. `types_cations.txt` — типы катионов
Файл содержит соответствие числовых кодов и свойств катионов.

**Формат:**
<код> <символ> <заряд> <атомный_вес>

**Пример:**
0 V 0 0
1 Na 1 22.9898
2 Mg 2 24.3050
3 Fe 3 55.8450

**Примечание:** Код `0` зарезервирован для вакансий.

---

### 2. `types_anions.txt` — типы анионов
Файл содержит соответствие числовых кодов и свойств анионов.

**Формат:**
<код> <символ> <заряд> <атомный_вес>

**Пример:**
1 O 2 15.999
2 N 3 14.007
3 Cl 1 35.453

**Примечание:** Заряд указывается как абсолютное значение (без знака минус). Учитывается только анион под номером один.

---

### 3. `ordering.txt` — последовательность катионов
Файл содержит 32 числа (коды катионов), определяющих тип катиона в каждой позиции.

**Формат:** 32 числа, разделённых пробелами (можно в одну или несколько строк).

**Пример (одна строка):**
1 2 2 2 2 3 2 2 2 2 2 2 2 2 2 2 2 2 3 2 1 2 3 2 1 2 2 2 2 2 1 3

---

### 4. `cation_positions.txt` — позиции катионов
Файл содержит 32 позиции катионов с координатами и CIF-параметрами.

**Формат:**
<номер> <x> <y> <z> <occupancy> <multiplicity> <Wyckoff> <H> <calc> <disp> <u_iso>

**Пример:**
1  0.5000  0.5000  0.2500  1.000 1 a ? d ? ?
2  0.2500  0.2500  0.2500  1.000 1 a ? d ? ?

---

### 5. `anion_positions.txt` — позиции анионов
Файл содержит 32 позиции анионов с дробными координатами.

**Формат:**
<номер> <x> <y> <z> <occupancy> <multiplicity> <Wyckoff> <H> <calc> <disp> <u_iso>

**Пример:**
1  0.0000  0.0000  0.0000  1.000 1 a ? d ? ?
2  0.0000  0.2500  0.2500  1.000 1 a ? d ? ?

---

## Выходные данные

### `output.cif` — CIF-файл
Содержит полную кристаллическую структуру в формате CIF:
- Заголовок с параметрами ячейки
- Типы атомов с зарядами и радиусами
- 32 катиона (C1...C32) с координатами и параметрами
- 32 аниона с координатами

---

## Алгоритм работы
1. Загрузка свойств катионов из `types_cations.txt`
2. Загрузка свойств анионов из `types_anions.txt`
3. Загрузка последовательности из 32 кодов из `ordering.txt`
4. Загрузка 32 катионных позиций из `cation_positions.txt`
5. Загрузка 32 анионных позиций из `anion_positions.txt`
6. ## Выбор аниона по коду (задаётся в программе)
7. Для каждой катионной позиции:
   - Определение кода катиона из `ordering.txt`
   - Преобразование кода в символ элемента
   - Запись в CIF с координатами из `cation_positions.txt`
8. Запись 32 анионов с координатами из `anion_positions.txt`
9. Расчёт химической формулы с сортировкой по заряду и сокращением коэффициентов
10. Сохранение CIF-файла

---

## Запуск
Import_to_cif.exe
Программа автоматически загружает все файлы и генерирует output.cif.

## Пример

### Исходные файлы

```text
types_cations.txt     # 0 V, 1 Na, 2 Mg, 3 Fe
types_anions.txt      # 1 O, 2 N, 3 Cl
ordering.txt          # 1 2 3 4 1 2 3 4 ...
cation_positions.txt  # 1 0.2500 0.2500 0.2500 ...
anion_positions.txt   # 1 0.0000 0.0000 0.0000 ...

```

### Выходной файл

```text
output.cif            # Полная структура в формате CIF
```
## Выбор аниона
По умолчанию программа использует анион с кодом 1 (первая строка в types_anions.txt).

Для смены аниона измените в файле Import_to_cif.cpp строку:

```cpp
int anion_code = 1;  // код из types_anions.txt
```
## Особенности
Вакансии (код 0): автоматически пропускаются при записи в CIF

Нумерация катионов: сохраняется исходная (C1, C2, C4... при наличии вакансий)

Химическая формула: катионы сортируются по возрастанию заряда, вакансии указываются как [], анион — последним

Сокращение коэффициентов: автоматическое приведение к наименьшему общему делителю

На данный момент программа генерирует все структуры в кубической примитивной ячейке фиксированного размера. Автоматический поиск минимальной (примитивной) ячейки пока не реализован

## Ограничения
Количество позиций фиксировано: 32 катиона и 32 аниона

Все координаты должны быть дробными (от 0.0 до 1.0)

Код 0 зарезервирован для вакансий
