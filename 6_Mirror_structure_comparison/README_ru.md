# Сравнение зеркальных структур

## Назначение

**Mirror_structure_comparison** сравнивает два CF32 между собой  и определяет, являются ли они:

- одинаковыми;
- эквивалентными по трансляции;
- эквивалентными по вращению;
- зеркальными (энантиоморфными);
- различными.

При обнаружении зеркальной пары автоматически создаётся публикационный CIF-файл:

`Mirror_paper_<StructureA>_vs_<StructureB>.cif`

## Научная основа

Сравнение выполняется на **решётке катионов CF32 4×4×4**.

Алгоритм перебирает:

- все трансляции;
- все собственные операции симметрии (det = +1);
- все несобственные операции симметрии (det = −1).

Сравнивается только катионная подрешётка, поскольку кислородный каркас одинаков для всех структур CF32.

## Рекомендуемый порядок работы

Сравнение следует выполнять **после программы Structure_import_to_CIF_format**.

```
Исходный CIF
      ↓
Reduce_cell
      ↓
Reduced CIF
      ↓
Mirror_structure_comparison
```

## В дальнейших расчетах мы используем только отсеянные ячейки и только одну левую зеркальную ячейку

## Компиляция

```bat
cl Mirror_structure_comparison.cpp /O2 /Oi /Ot /EHsc /Fe:mirror_structure_comparison.exe
```

## Запуск

```text
mirror_structure_comparison.exe Reduced_A.cif Reduced_B.cif
```

## Результат

Программа сообщает, являются ли структуры эквивалентными по трансляции, вращению, зеркальными (энантиоморфными) или различными.

Для зеркальной пары дополнительно создаётся файл:

`Mirror_paper_<StructureA>_vs_<StructureB>.cif`
