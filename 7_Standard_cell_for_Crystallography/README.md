# Standard_cell — Standard crystallographic cell builder

## Purpose

`Standard_cell` converts a reduced primitive chemical cell into a more conventional crystallographic cell representation when such a representation can be found.

The program is intended to make structures easier to inspect, visualize, compare with published crystallographic data, and prepare for reports or publications.

It does **not** search for the smallest primitive cell. That task is handled by a separate reduction module, such as `Reduce_cell_CF32`.

```text
Generated CIF
        |
        v
Reduce_cell_CF32
        |
        v
Reduced CIF
        |
        v

        |
        v
Standard CIF
```

Example:

```text
phase_6.cif
        |
        v
Reduced_phase_6.cif
        |
        v
Standard_phase_6.cif
```

---

## Scientific idea

A primitive cell is the smallest possible translational cell, but it is not always the most convenient crystallographic representation.

For example, MgO in the NaCl structure can be described by:

- a primitive rhombohedral cell with 2 atoms;
- a conventional cubic F-centered cell with 8 atoms.

Both descriptions are correct, but the conventional cubic cell is usually more recognizable and easier to compare with literature.

`Standard_cell` attempts to find a conventional-like cell by analyzing the metric of the reduced primitive cell.

---

## How it works

The program:

1. Reads a reduced CIF file.
2. Builds primitive cell vectors from the CIF cell parameters.
3. Generates candidate cells using small integer transformation matrices.
4. Calculates the metric of each candidate cell.
5. Classifies the metric approximately as:
   - cubic;
   - tetragonal;
   - orthorhombic;
   - hexagonal;
   - rhombohedral;
   - monoclinic;
   - triclinic.
6. Scores candidate cells by crystallographic simplicity.
7. Selects the best conventional-like cell.
8. Expands atoms into the selected standard cell.
9. Writes a new standard CIF file.
10. Prints an explanation of why the selected cell was chosen.

## Input

The input should normally be a reduced primitive CIF file.

Example:

```text
Reduced_phase_6.cif
```

Recommended command sequence:

```bat
reduce_cell_cf32.exe phase_6.cif
standard_cell_cf32.exe Reduced_phase_6.cif
```

---

## Output

The output file is created automatically.

Example:

```text
Reduced_phase_6.cif
```

becomes

```text
Standard_phase_6.cif
```

If the input filename starts with `Reduced_`, this prefix is removed in the output name.

```text
  ...

Selection reason:
  - Candidate cells were generated by small integer transformations
    of the reduced primitive cell.
  - The selected cell has the highest detected metric symmetry
    among the tested candidates: cubic.
  - The metric is cubic because a = b = c and all angles
    are close to 90 degrees.
  - Within the same metric class, the program prefers smaller
    supercells and shorter basis vectors.
  - This is a metric standardization only; the program does not
    determine the full space group or Wyckoff positions.

```

## Selection criteria

The program prefers candidate cells in the following general order:

```text
cubic
    ↓
tetragonal
    ↓
orthorhombic
    ↓
rhombohedral / hexagonal
    ↓
monoclinic
    ↓
triclinic
```

Within the same metric class, it prefers:

1. smaller supercell index;
2. smaller metric penalty;
3. shorter basis vectors.

## Important distinction

`Standard_cell` does not replace `Reduce_cell_CF32`.

They solve different problems.

### Reduce_cell_CF32

```text
Finds the smallest primitive chemical cell.
```

This is best for:

- DFT calculations;
- removing redundant translations;
- reducing the number of atoms.

### Standard_cell

```text
Builds a more conventional crystallographic representation.
```

This is best for:

- visualization;
- comparison with published structures;
- preparing figures;
- human-readable crystallographic descriptions.

---

## Limitations

The program performs **metric standardization**, not full symmetry analysis.

It does not determine:

- full space group;
- symmetry operations;
- Wyckoff positions;
- conventional setting according to International Tables.

For final crystallographic assignment, especially after DFT relaxation, use specialized tools such as:

- spglib;
- FINDSYM;
- VESTA;
- pymatgen;
- Materials Project tools.

---

## Current implementation notes

The current implementation enumerates small integer transformations of the primitive cell.

This is sufficient for many reduced structures produced from CF32 superstructures, such as MgO-like or tetragonal examples.

For larger systems such as CF108, the module can be extended by increasing the transformation search range or by adding a more formal lattice reduction / standardization algorithm.
