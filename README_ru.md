# ГЕНЕРАТОР СВЕРХСТРУКТУР ТИПА NaCl

## НАЗНАЧЕНИЕ

Программа реализует комбинаторный подход к моделированию сверхструктур
типа NaCl. Алгоритм основан на переборе всех возможных вариантов
заполнения катионной подрешётки в кубическом фрагменте (CF32/CF108)
с последующей проверкой глобальной электронейтральности и локального
баланса валентностей (правило Полинга). В результате генерируются
стехиометрические составы и сверхструктурные модели, которые могут
быть сопоставлены с реальными сложными оксидами.

## ОБЗОР

Программа состоит из нескольких модулей с документацией:
1. **`Stoichiometry_generator`** — генератор стехиометрий с учетом глобального баланса валентностей для CF32/CF108
2. **`Structure_generator`** — генератор структур на базе найденных стехиометрий с учетом локального баланса валентностей
3. **`Filter_g_compatible`** — отсев геометрически совместимых структур
4. **`Filter_interpenetrating`** — отсев геометрически совместимых структур
5. **`Structure_import_to_CIF_format`** — импорт структуры в формат CIF для программ DIAMOND/VESTA

## КОМПИЛЯЦИЯ

Программа написана на стандартном C++ и компилируется с использованием Microsoft Visual Studio.

**Среда компиляции:**
- Visual Studio 2022 Developer Command Prompt v17.14.25
- Microsoft (R) C/C++ Optimizing Compiler Version 19.44.35222

**Среда выполнения:** CMD/Powershell (Windows 10/11)

**Пример команды компиляции:**
```cl Stoichiometry_84.cpp /O2 /Oi /Ot /EHsc /Fe:stoichiometry_84.exe```

Пояснение флагов компилятора:

/O2 — Максимальная оптимизация по скорости

/Oi — Генерация встроенных функций

/Ot — Предпочтение скорости размеру кода

/EHsc — Включение обработки исключений C++

/Fe — Указание имени выходного исполняемого файла
